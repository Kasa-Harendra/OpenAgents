## 2024-05-17 - Keyboard Accessibility & ARIA Labels in Interactive Elements
**Learning:** Found a common anti-pattern where interactive elements used for toggling state (like expand/collapse arrows in `ChatMessage` and `SystemMessageGroup`) were implemented as `div` tags with `onClick` handlers. This makes them completely invisible to keyboard navigation. In addition, numerous icon-only buttons across the app lacked `aria-label`s, rendering them inaccessible to screen readers.
**Action:** Always use `<button>` elements for interactive actions rather than adding `onClick` to `div`s. For `<button>`s, ensure `focus-visible:outline-none focus-visible:ring-2` (or similar) is set for keyboard focus indication. When creating an icon-only button, an `aria-label` is mandatory for screen readers, even if a `title` attribute is present.
